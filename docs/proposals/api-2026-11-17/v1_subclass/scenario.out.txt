# 2 · pick M3.stribeck
>>> from subclass_ladder.servo import Stribeck
>>> print(Stribeck.describe())
M3.stribeck · class Stribeck(CoulombViscous) · Stribeck friction: breakaway falling to Coulomb with speed
  tau_r = (coulomb_friction + (breakaway_torque − coulomb_friction)·exp(−(|v|/stribeck_velocity)^stribeck_exponent))·sign(v) + viscous_friction·v
  needs breakaway_torque [N·m]: Static friction at the output: the torque that starts it moving from rest, the top of the Stribeck curve.
  needs stribeck_velocity [rad/s]: Output speed over which friction falls from breakaway_torque to coulomb_friction.
  reads stribeck_exponent [1]: Shape exponent of the Stribeck curve, how sharply friction falls with speed; 2 when absent.
  inherits output_inertia [kg·m²], gear_ratio [1], coulomb_friction [N·m], viscous_friction [N·m·s/rad]; reads 31 more when stated
  cites Armstrong-Hélouvry, Dupont, Canudas de Wit (1994); Olsson, Åström, Canudas de Wit, Gäfvert, Lischinsky (1998)
  runs actuators/rungs/stribeck/model.py · also at M3: M3.load, M3.lugre, M3.weakening_capture
