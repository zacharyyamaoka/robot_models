## 2. Pick M3.stribeck: parameters, units, equation, references, fallback; resolve an alias
>>> stribeck = servo["M3.stribeck"]
>>> print(stribeck)
M3.stribeck  Stribeck friction: breakaway falling to Coulomb with speed
  base      M2.coulomb_viscous
  inherits  output_inertia [kg·m²], gear_ratio, coulomb_friction [N·m], viscous_friction [N·m·s/rad]
  adds      breakaway_torque [N·m]: Static friction at the output: the torque that starts it moving from rest, the top of the Stribeck curve.
            stribeck_velocity [rad/s]: Output speed over which friction falls from breakaway_torque to coulomb_friction.
  optional  stribeck_exponent (+31 inherited, read when stated)
  equation  tau_r = (coulomb_friction + (breakaway_torque − coulomb_friction)·exp(−(|v|/stribeck_velocity)^stribeck_exponent))·sign(v) + viscous_friction·v
  refs      Armstrong-Hélouvry, Dupont, Canudas de Wit (1994)… https://doi.org/10.1016/0005-1098(94)90209-7
            Olsson, Åström, Canudas de Wit, Gäfvert, Lischinsky (1998)… https://doi.org/10.1016/S0947-3580(98)70113-X
  physics   actuators/rungs/stribeck/model.py: torque(v [rad/s]) -> tau_r [N·m]; a fit varies coulomb_friction, viscous_friction, breakaway_torque, stribeck_velocity
>>> servo.fallback("M3.stribeck")

## 4. Fit M2.coulomb_viscous and M3.stribeck to the rig log

>>> m3 = stribeck.fit(log["tau"], v=log["v"], values=values)
>>> print(m3)
