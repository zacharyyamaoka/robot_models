# 2. Pick M3.stribeck: a preset is a named composition; climbing to it swaps one slot
>>> m3 = servo["M3.stribeck"]
>>> m3 == servo["M2.coulomb_viscous"].redeclare(friction="stribeck")
True
>>> print(m3.describe())   # each term's equation, what the model needs (units, meaning), what it reads, references
M3.stribeck = inertia:ideal + friction:stribeck
  inertia:ideal      tau_r = 0; armature = output_inertia
  friction:stribeck  tau_r = (coulomb_friction + (breakaway_torque − coulomb_friction)·exp(−(|v|/stribeck_velocity)^stribeck_exponent))·sign(v) + viscous_friction·v
  needs output_inertia     kg·m²      The part's own inertia about its axis, referred to the output (MuJoCo's armature).
        gear_ratio         —          Rotor turns per output turn, > 0: 10 for a 10:1 reducer.
        coulomb_friction   N·m        Coulomb friction torque at the output.
        viscous_friction   N·m·s/rad  Viscous friction coefficient at the output.
        breakaway_torque   N·m        Static friction at the output: the torque that starts it moving from rest, the top of the Stribeck curve.
        stribeck_velocity  rad/s      Output speed over which friction falls from breakaway_torque to coulomb_friction.
  reads 32 more when stated (.optional): peak_torque, rated_torque, max_output_speed, …, stribeck_exponent
  refs  Siciliano, Sciavicco, Villani, Oriolo (2009) · MuJoCo (2026) · Armstrong-Hélouvry, Dupont, Canudas de Wit (1994) · Olsson, Åström, Canudas de Wit, Gäfvert, Lischinsky (1998)

# 4. Fit M2.coulomb_viscous, then climb one slot to M3.stribeck and fit again on the same rig log
>>> log = rig_log()   # velocity plateaus, both directions: v [rad/s], tau [N·m]
>>> m2_fit = servo["M2.coulomb_viscous"].fit(log, start=m1)
