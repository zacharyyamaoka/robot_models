>>> stribeck = servo.model("M3.stribeck")
>>> print(stribeck.describe())
M3.stribeck  Stribeck friction: breakaway falling to Coulomb with speed
  falls back  M3.stribeck → M2.coulomb_viscous → M1.datasheet → M0.ideal   (siblings: M3.load, M4.ripple)
  needs       output_inertia [kg·m²], gear_ratio [1], coulomb_friction [N·m], viscous_friction [N·m·s/rad], breakaway_torque [N·m], stribeck_velocity [rad/s]
  fits        coulomb_friction, viscous_friction, breakaway_torque, stribeck_velocity
  optional    stribeck_exponent [1] (+31 datasheet fields below it, read when stated)
  equation    tau_r = (coulomb_friction + (breakaway_torque − coulomb_friction)·exp(−(|v|/stribeck_velocity)^stribeck_exponent))·sign(v) + viscous_friction·v
  reference   Armstrong-Hélouvry, Dupont, Canudas de Wit (1994). A survey of models, analysis tools and compensation methods for the control of machines with friction. Automatica.
  reference   Olsson, Åström, Canudas de Wit, Gäfvert, Lischinsky (1998). Friction models and friction compensation. European Journal of Control.

# Step 3 · The datasheet model: M1 from the stated values, then predict
>>> from fixture import datasheet, rig_log
>>> ds = datasheet()                              # the catalogue's units: rpm, kg·cm², mN·m·s/rad
>>> m1 = Model.from_datasheet(ds)                 # M1.datasheet by default: every stated value it holds, in SI
>>> print(m1)
M1.datasheet: not fitted
  stated   output_inertia 4.2e-05 kg·m², gear_ratio 10, peak_torque 3.5 N·m, rated_torque 1.05 N·m, max_output_speed 24.09 rad/s, coulomb_friction 0.3 N·m, viscous_friction 0.02 N·m·s/rad
>>> m1.predict(1.0)                               # tau_r at 1 rad/s [N·m]
0.32

# Step 4 · Fit M2 and M3 to the rig log
>>> log = rig_log()                               # velocity plateaus, both directions: v [rad/s], tau [N·m]
>>> m2 = Model.from_datasheet(ds, "M2.coulomb_viscous").fit(log)
>>> m3 = Model.from_datasheet(ds, "M3.stribeck").fit(log)    # starts from the datasheet; the rest is scanned
>>> print(m2)

>>> print(m3)
