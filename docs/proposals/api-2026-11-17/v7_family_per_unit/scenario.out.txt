>>> print(Stribeck.describe())
M3.stribeck · class Stribeck(CoulombViscous) · Stribeck friction: breakaway falling to Coulomb with speed
  tau_r = (coulomb_friction + (breakaway_torque − coulomb_friction)·exp(−(|v|/stribeck_velocity)^stribeck_exponent))·sign(v) + viscous_friction·v
  needs breakaway_torque [N·m] (required): Static friction at the output: the torque that starts it moving from rest, the top of the Stribeck curve.
  needs stribeck_velocity [rad/s] (required): Output speed over which friction falls from breakaway_torque to coulomb_friction.
  reads stribeck_exponent [1] (optional): Shape exponent of the Stribeck curve, how sharply friction falls with speed; 2 when absent.
  inherits output_inertia, gear_ratio, coulomb_friction, viscous_friction; reads 31 more when stated
  cites Armstrong-Hélouvry, Dupont, Canudas de Wit (1994); Olsson, Åström, Canudas de Wit, Gäfvert, Lischinsky (1998)
  falls back M2.coulomb_viscous -> M1.datasheet -> M0.ideal
